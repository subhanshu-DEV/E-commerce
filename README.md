# 🛒 E-Commerce Backend

A REST API project built using Java, Spring Boot, and MySQL to manage e-commerce products.

## 🚀 Features
- Create, Read, Update & Delete Products (CRUD)
- Input Validation
- Global Exception Handling
- MySQL Database Integration

## 🛠️ Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## ⚙️ Setup
1. Clone this repository.
2. Configure MySQL in `application.properties`.
3. Run `EcommerceBackendApplication.java`.
